### 공통 틀

- **상단 바** · 로고(로그인 후엔 홈으로) · 탭 **검사**(3·4·5) · **이력**(6·7·8) · 6·8에 "재검사" · AI 표시("AI 연결됨" · "AI 확인 중…" · "AI 없음", "AI 확인 중…"은 AI 설정 응답을 기다리는 동안. 누르면 AI 연결 팝업) · 검사 상태 칩(AI 표시 왼쪽. "검사 전" · "검사 중"(빨간 점) · "검사 멈춤"(주황 점, 딸깍 재시작으로 멈춘 회차 -228) · "검사 완료", 0-3 제외 — 누르면 "검사 시작" 팝업 · 그 회차 5 · 그 회차 5(이어서 검사할지 묻기) · 그 회차 6. 팝업은 지금 상태 두 줄("서비스 · order-api · 연결됨" · "코드 · GitHub owner/order-api · main" / "코드 연결 안 함")과 상태대로 버튼 하나 — 저장한 코드 연결이 있으면 "딸깍 검사 시작"(바로 3), 없으면 "소스코드 연결하러 가기"(0-3 ④), 연결된 서비스가 없으면 "서비스 연결하러 가기"(0-3). 코드 연결을 받는 동안은 "확인 중…"(꺼짐), 못 받으면 "딸깍 검사 시작"(누르면 홈 · 코드 연결을 다시 받아 갈 곳을 정함) · 닫기 (-245). 결과를 열면 서버는 검사 전으로 바꾸지만 그 결과(6 · 7)를 보는 동안은 검사 완료로 두고, 다른 페이지로 옮기면 검사 전, -214) · admin ▾(AI 연결 · 로그아웃)
- **검사 시작** · 홈 딸깍 검사 · 상단 탭 "검사" · 6 · 8 "재검사"는 모두 같다 — 저장한 코드 연결이 있으면 바로 3, 없으면 0-3 ④, 연결된 서비스가 없으면 0-3. 홈 딸깍 검사만 하나 더 — 서비스가 끊겼고 같은 앱의 다시 허용 요청이 와 있으면 0-3 ②(-211. 나머지 진입점은 바로 3으로 가 `SERVICE_OFFLINE` "앱이 꺼져 있어요"). 코드 연결 화면을 거치지 않는다. 흐름 화면 위 단계 줄은 ① 검사 범위 분석 · ② 검사 범위 선택 · ③ 검사 진행 · ④ 완료 (-245)
- **검사 중 알림** · 검사 중에 새 검사를 시작하려 하면(홈 딸깍 검사 · 상단 탭 "검사" · 409 `RUN_IN_PROGRESS`) 그 화면으로 들어가지 않고 하단 바 대신 팝업 "이미 검사 중이에요 · 검사는 한 번에 하나씩 해요. 지금 검사가 끝나면 새로 시작할 수 있어요" · 진행 화면 보기 · 닫기 (-214)
- **하단 바** · 시스템 메시지(1.8초). 바는 화면에 붙이지 않고 페이지 맨 아래에 둔다 — 긴 화면은 끝까지 내려야 보이고, 짧은 화면은 창 맨 아래에 놓인다. 메시지만 창 오른쪽 아래에 마젠타 상자(#9e4f92 `--magenta-600` — 흰 글자 대비 5.3:1, 프레임 #b45ca6은 4.2:1이라 AA 4.5 미달)로 띄워 긴 화면에서도 스크롤 없이 보인다 (-249)
- **키보드 단축키 없음** · 화면별 ENTER · ESC · ↑↓ 같은 단축키와 그 안내를 두지 않는다. 팝업도 ESC로 닫히지 않는다(✕ · 버튼으로만). Tab 이동과 버튼의 ENTER · 스페이스 같은 브라우저 기본 조작은 그대로 (-212)
- **스크롤바** · 기본 스크롤바 없이 화면 오른쪽에 겹치는 얇은 막대(폭 6px · 각짐 · ink-400). 스크롤하거나 마우스를 올리면 보이고 1초 뒤 사라진다. 끌어서 스크롤할 수 있다. 화면마다 레이아웃이 좌우로 밀리지 않게
- **설정 화면 없음** · 상단 탭은 검사 · 이력만
- **배경** · 별 필드 · 상단 바 · 하단 바와 그 위 64px 띠는 바위 이미지(`nav-rock-2` · `nav-edge` · `footer-rocks-2`, 바탕 #303a60 `--rock-700`, -259) · 로켓 · 걷는 우주 햄스터. 모든 움직임은 steps(), 블러·이징 없음. 예외: 0-0 → 1 화면 전환 · 로그인 뒤 별 배경 fade-in은 ease-in/out (§4, -259)
- **프로토타입 전용** · 상단 "STAGE SELECT" 화면 이동 바는 구현하지 않는다
- **0-0 소개** · 상단 바 · 하단 바는 그대로, 배경의 로켓 · 걷는 햄스터 대신 소개 연출(§2 0-0)

## 2. 화면별

### 0-0 소개

- 첫 설치 때만 보인다 (`GET /api/setup`의 `needsAck: true`). 확인을 마친 뒤 접속하면 보이지 않고 0-2 · 1로 간다
- 왼쪽 · "AI SERVICE CHECK" · 큰 제목 "DDalKKaK" / 오른쪽 · 아케이드 빨간 큰 버튼 "시작하기"(이미지 3장: 받침 · 바위 · 작은 행성 `btn-base` → 눌리는 캡 `btn-cap` → 앞면 `btn-front`, -259) → 0-1. 이미 확인을 마쳤으면(URL로 직접 들어온 경우) → 0-2
- 연출 · 햄스터 2마리가 걸어와 사다리를 세우고 올라가 버튼 위에 착지(버튼이 눌림) · 말풍선 "도와줘. 딸깍!". 타이밍은 Pixel Flow HTML `runHamScene()`
- 지원 창 비율 · 16:9 · 16:10 (1366×768 ~ 2560×1440). 1024×768 · 1280×1024처럼 폭이 좁은 창은 버튼 오른쪽이 창 밖으로 잘린다 — 동작(캡 누르기)은 그대로 된다 (!153 리뷰 2-3, 디자인 크기를 지키려고 줄이지 않기로 함)

### 0-1 설치

- 아이디 `admin` · 자동 생성 비밀번호 + 복사 · "지금 한 번만 보여요 · 창을 닫으면 다시 볼 수 없어요. 터미널 로그에도 같은 값이 출력돼 있어요" · "저장했어요" 체크 → "로그인하러 가기"(체크 전 비활성) → 0-2
- 전환 (-259, Pixel Flow `blackHole` · `open0a` · `toLogin`) · 0-0 시작하기는 버튼이 눌린 뒤 0.4초 있다 넘어온다. 들어올 때 왼쪽 카드 · 오른쪽 칸이 가운데에서 펼쳐지고, "로그인하러 가기"를 누르면 가운데로 모이며 사라진 뒤 0-2. 움직임 줄이기면 효과 없이 바로

### 0-2 로그인

- 아이디 · 비밀번호 · 로그인 · 글자 버튼 "비밀번호를 잊었어요" → 팝업 "비밀번호 다시 만들기": "docker run으로 설치했다면 `docker exec ddalkkak ddalkkak reset-password`" · "Compose로 띄웠다면 `docker compose exec ddalkkak ddalkkak reset-password`" (README 설치 명령 · Compose 예시 기준, -151 · 화면 아래 안내 줄은 팝업으로 옮김 -249)
- 전환 (-259) · 0-1에서 넘어오면 카드가 작게 시작해 살짝 커졌다 제자리로. 로그인에 성공하면 카드가 살짝 커졌다 작아지며 사라진 뒤(0.6초) 0-3 · 1, 그 화면은 아래에서 올라오며 나타나고 4각 별 배경이 서서히 나타난다. 401 · 로그아웃으로 온 로그인은 효과 없음

### 0-3 온보딩

- 한 화면에 한 단계 · ① 스타터킷 추가 → ② 서비스 연결 → ③ AI 키 추가 → ④ 소스코드 연결 → 1. 단계는 하단 버튼으로만 넘어간다(키보드 단축키 없음, -212). 지금 단계는 주소 `#/onboarding/{1~4}`라 새로고침해도 그대로다 (-222). 단 ① · ② 주소는 정상 연결이면 1로 간다 — ③ · ④만 늘 그대로 (F-CONN-08, -223)
- 단계 칩 ① 스타터킷 추가 · ② 서비스 연결 · ③ AI 키 추가 · ④ 소스코드 연결 — 지나온 단계 ✓ 초록 외곽, 지금 단계 시안 채움, 남은 단계 회색. ③을 AI 키 없이 지나왔으면 ✓ 대신 "③ AI 키 추가 건너뜀"(회색 점선, -250)
- 하단 · "이전"(②~④) · "나중에"(서비스 연결 전, 어느 단계든 → 1) · "다음"(④는 "홈으로" — ④에서 카드를 고르거나 값을 넣고 아직 연결하지 않았으면 "연결하지 않고 홈으로", -250). ②는 연결 전엔 "허용하면 다음"으로 막힌다. 연결 여부는 이 화면에서 허용했거나 들어올 때 `GET /api/home`의 `service.connected`
- ① 스타터킷 추가 · 제목 "검사할 서비스에 딸깍 스타터킷을 넣어주세요" · 부제 "서비스 런타임에 붙는 작은 라이브러리예요 · 설정 없음, AI 코딩 도구가 넣어 줘요"
